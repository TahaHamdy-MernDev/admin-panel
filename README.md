# Admin Panel — Operations Dashboard

A modular, multi-language operations and management dashboard built with Next.js, TypeScript, Tailwind CSS, and Radix UI / Shadcn UI primitives.

## Live Demo

- **Production:** [admin-panel-sage-phi.vercel.app](https://admin-panel-sage-phi.vercel.app)

## Architecture & Highlights

- **Feature-Sliced Structure:** Organized by domain modules (`features/`, `components/`, `hooks/`, `lib/`, `i18n/`).
- **Accessible UI Primitives:** Built on Radix UI dialogs, dropdowns, popovers, checkboxes, and responsive data views.
- **Strict Type Safety:** TypeScript `strict: true` with React Hook Form + schema resolvers.
- **Internationalization:** Built-in multi-locale routing and RTL/LTR direction support.
